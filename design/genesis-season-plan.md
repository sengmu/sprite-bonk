# Sprite Bonk 创世赛季与链上奖励路线图

2026-11-20。适用于 Android Compose 版。首季奖励为游戏内权益，后续链上分发与项目代币发行均待独立评审。

## 首季玩法

首页提供「创世赛季」入口，显示赛季期限、挑战进度和可领取奖励。游客能参与并在当前设备查看进度。玩家可选择建立可恢复账户，并通过钱包签名绑定地址。

| 挑战 | 判定 |
| --- | --- |
| 密林守卫 | 在经典模式击败翡翠密林的守护者并完成结算 |
| 伙伴历练 | 使用三只不同伙伴分别完成一次经典模式守护者挑战 |
| 再战密林 | 使用同一伙伴在三个不同的赛季日完成密林守卫挑战，赛季日按 UTC 计算 |

完成全部挑战可领取一件确定的奖励：**创世纪念·雷铃狐外观**。领取后进库存，和商店销售的雷铃狐外观使用不同商品与权益标识。赛季起止时间、领奖截止时间和正式外观名称在发布前核定。

## 进度、奖励与消费

- 服务端保存赛季与规则版本、玩家标识、战斗标识、伙伴、地图、模式、守护者击败及结算结果。客户端上报是待核验记录。若战斗尚无法服务端复核，先按游戏内活动使用这些记录，不据此发放有市场价值的资产。
- 同一战斗重复提交只记一次，同一玩家同一奖励只发一次。账户绑定后按战斗标识合并可核验的游客记录。明确展示本机进度和账户已同步进度，离线记录恢复联网后再同步。
- 星尘来自游玩，沿用成长用途。SKR 商店采用逐单购买，支付后发对应商品。SKR 消费、充值、交易量和邀请不作为空投加权条件。详见 [商店规划](solana-commerce-plan.md)。
- 对外可写「完成首季挑战，解锁限定外观并保留赛季记录」。路线图可写「评估链上社区奖励」。当前没有积分兑币比例、发币日期或空投资格承诺。

## 后续评审

1. 首季结束后看挑战完成率、回访和商店转化。只有项目代币存在独立于 SKR 和星尘的长期用途，才进入发行评审。
2. 对外宣布前，由专业顾问确认发行主体、目标地区、分发方式、宣传文案及渠道要求。中国大陆相关限制和美国 SEC 空投解释都需结合具体安排审查。[中国监管通知](https://www.csrc.gov.cn/csrc/c100028/c7614318/content.shtml) · [美国 SEC 解释](https://www.sec.gov/files/rules/interp/2026/33-11412.pdf)
3. 若获批，再公开快照范围、资格、反作弊、申诉期和领取期限。历史赛季记录可作为候选依据。发行方案另行确定供应量、社区分配、团队解锁、金库权限和披露，独立于游戏销售收入。

## 实施验收

先出赛季首页、挑战详情与领奖流程稿，再接入服务端记录和库存。用 Seeker 验证游客可开玩、任务按规则累计、重复结算或领奖不会重复发货、换设备后可恢复已同步进度与权益。首季验收不依赖链上代币发行。
