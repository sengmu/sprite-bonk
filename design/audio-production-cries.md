# 伙伴叫声生产记录（audio/cries 分支，2026-11-11）

## 缘起

SFX 与 BGM 两线收口后，音频只剩伙伴叫声（cry）还是占位：旧实现
是按物种 id 哈希的 22050 Hz 合成啁啾（audio.gd 自注「structural
placeholder」）。用户 2026-11-11 21:40 拍板方向：「继续免费合成」。

## 范围

需求单 CH-01/CH-02 的原始口径是：CH-01 三只初始伙伴各 1 个原创声；
CH-02 首发用小/中/大三档通用声兜底，54 个物种各一个声列 P2、
等物种名定稿。本批按下列口径执行（超出清单字面、方向更彻底）：
叫声的 key 是内部物种 id，与展示名无关，物种名定稿不阻塞声音
生产；故直接把 P2 的目标一次做完——**游戏能出场的全部 159 个
物种（79 个家族的全部成长阶段，含化石 omanyte/kabuto/aerodactyl、
商人 meowth、事件 rhydon）各 1 个原创叫声**，三档通用声作为
未列名 id 的回退一并生产。出场集合由检查脚本从仓库数据
（roster.json × pokemon.json）现算，与游戏同源，不靠手抄名单。

## 配音系统（generate_cries.py，全部原创合成）

- **家族定调**：以家族 id 为种子定型（音节型、轮廓、颤音），
  同族叫声可辨认是亲戚；物种级变化由个体种子补足。
- **体型定音高**：以体重在全集中的分位映射基频（880 Hz 小型 →
  175 Hz 巨型）；成长阶段逐阶降低（×0.93/阶）、拉长、加音节。
- **属性定音色**：17 种主属性风味——水系气泡 FM、草系颤音
  啁啾、火系呼吸噪声、电系蜂鸣颤音、岩/地/钢系砂砾低通、
  幽灵/超能系五度叠音长攻击、虫系颤音门控、冰系高频泛音、
  妖精系铃音、龙系次八度共鸣、恶系粗糙 AM 等）。
- **初始三家手工设计**（按已定版的换皮身份，不按其内部 key 的
  原型）：树桩洞傀（家 1）= 木质敲击 + 洞里闷住的两声啁啾；
  冷炭裂膛（家 4）= 低频呼吸咆哮 + 炭火爆裂声（首版爆裂声全频
  太亮、频谱重心 8000 Hz 不像咆哮，已低通到 2200 Hz 并降增益，
  复测重心 1210–1394 Hz）；对旋双壳（家 7）= 壳扣轻响 + 旋转
  气泡哨音（转速随成长变慢）。
- 传说/幻之物种加一层八度微光回声。
- 交付规格同前：WAV 16-bit / 44.1 kHz / 单声道、峰值 −1 dBFS、
  RMS 均衡（全集 0.108–0.170，无物种明显偏小声）。

生成端 QA：162 个文件（159 + 3 回退）格式全检通过；时长
0.18–1.10 s；峰值 ≤ 0.890、削波 0；频谱重心 329–8385 Hz、
64 个可辨识的 50 Hz 分箱；双壳家族重心随成长单调下降
（689 → 552 → 456 Hz）。

## 代码改动（逐项列明）

仅 scripts/audio.gd 的叫声段：
- 新增 `cry_stream_for(species_id)`：解析链 = 本物种文件
  （cry_<id>.wav）→ 通用回退文件（按 id 哈希分桶 s/m/l）→
  旧哈希合成（仅作开发安全网，M5 门禁删除）；解析结果进
  原 `_cry_streams` 缓存。
- `cry()` 改为经 `cry_stream_for` 取流，播放器/音高/计数
  语义不变。调用点零改动（16 处 cry 调用、化石回调、
  cry("meowth")/cry("rhydon") 字面量全部自动命中文件）。

说明：回退分桶按 id 哈希而非体型数据库——需求单 §六的「三档
兜底」本意是首发有声可用，本批全物种覆盖已使回退在现行数据
下永不触发，分桶只防未来新增未配音 id，不谎称体型真值。
