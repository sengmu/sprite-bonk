## 硬性要求（官方口径）

| 项 | 要求 | 来源 |

## 版式与安全区（本稿定版，设计约束）

- **图标叠压区**：详情页图标叠在 banner 上（通常压左下/左侧区域）——
  该区域只放背景纹理，不放关键视觉主体和任何文字。
- **文字安全区**：如需放字，只放右侧上半区，字高 ≤ 画布高 12%；
  首选**无文字版**（应用名由详情页 UI 本身呈现，图上加字易与 UI 重复）。
- **主体安全区**：主视觉（换皮后的主角/场景）放画面中右部，
  四边各留 ≥ 60 px 的呼吸边，裁切不伤主体。

## 文案位

- 允许出现：应用名 `SpriteBonk`（唯一允许的文字，且优先不放）。
- 禁止出现：任何第三方 IP 名词/形象、代币或收益类承诺字样
  （$SPRT / Genesis / 赚钱等一律不上图，守 R24 不误导口径）、
  价格与“限时”类营销字样。

## 素材来源（换皮后）

1. 首选：换皮后实机画面 1920×1080 渲染（与 M1 截图重渲同批产出）
   取景裁切至 1200×600；
2. 次选：换皮后的自有 IP 主角立绘/场景原画，按安全区合成；
3. 禁止：现有 4 张 1280×720 截图（IP 占位内容 + 分辨率不足）、
   宝可梦等第三方素材、reference/orig_assets 里的任何文件。

## 交付与验收（M1 执行时）

- 文件：`store/media/banner-1200x600.png`（与 config.yaml 的 media 口径对齐）；
- 验收：尺寸精确 1200×600、文件大小合理（参照截图 ≤3 MB 口径自检）、
  图内 grep 级自查 = 无 IP 名词文字、无代币承诺字样；
- 顺序：M3 换皮定版 → 截图/banner 同批重渲 → M1 checker 一起验，
  不单独先行做 banner。
