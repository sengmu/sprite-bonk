# KYC/KYB 启动指南 — 给用户（一页）

为什么先看这一页：**Publisher Portal 的身份验证不过，连 App 都建不了**
（官方原文：验证可以建档案时先跳过，但“you can't add a dApp until you
are approved”）。这是上架关口里唯一的排队项，越早起头越不堵后面。
其余材料（文案、隐私/条款稿、banner 规格）已在本目录备齐，不用你管。

来源：docs.solanamobile.com — *Submit a New App*（2026-10-24 修订），
https://docs.solanamobile.com/dapp-store/submit-new-app

## 步骤（照官方流程，共 4 步到验证）

1. **注册 Publisher Portal**（publish.solanamobile.com）：用邮箱+姓名+密码
   注册，登录用邮箱收到的验证码。账号密码是你本人的，我们不经手。
2. **建发布者档案**：选个人（individual）还是组织（organization），填名称
   和**网站**——网站必须是公开可达、且是介绍这个 App/公司/你本人的页面
   （没有现成网站的话，这项要先定：用哪个页面做发布者网站，属关口决策）。
3. **做身份验证**：个人走 **KYC**、公司走 **KYB**，在档案里发起，按验证
   环节的提示一步步交材料（官方文档没有列死材料清单，以验证页面当时
   要求为准）。
4. **等批准**：批准后才能在门户里 Add dApp。卡住时的官方求助路径：
   进 Solana Mobile Discord 的 `#developer` 频道拿 Developer 角色，
   再到 `#dev-answers` 开一张 **KYC / KYB Verification Issue** 工单
   （工单只有你和 Solana Mobile 团队可见）。

验证之后的第 5 步（连发布者钱包）先不用动：那必须是**只用于发布的
新钱包**、放少量 SOL 付铸造费——绝不用主钱包/交易钱包，这是既定关口，
等验证批了再一起办。

## 备材料清单（发起前备好，免得中途断档）

- [ ] 常用邮箱（注册 + 收审核结果邮件都用它，审核结果由
      publishersupport@dappstore.solanamobile.com 发出）
- [ ] 发布者主体决定：个人 还是 组织（定了才能选 KYC 还是 KYB）
- [ ] 与主体一致的法定姓名（个人）/ 组织注册名称（组织）
- [ ] 政府签发的身份证件（个人 KYC 通常要求；官方文档未列明细，
      以验证页面提示为准）
- [ ] 组织走 KYB 时：组织注册/营业执照类文件（同上，以提示为准）
- [ ] 发布者网站：一个公开可达的 HTTPS 页面（介绍 App/公司/开发者）

## 预计耗时（如实说）

- **KYC/KYB 审批时长：官方文档没有给出**，所以无法承诺几天能过——
  这正是要尽早启动的原因。
- 另一个常被混淆的数字：**3–4 个工作日**是「App 提交后」的审核出结果
  时间（官方 After Submission 一节），不是 KYC 的时长，别拿它估 KYC。
- 提交后 5 个工作日没回复，才走 `#dev-answers` 的 App Review Inquiry。

## 注意事项

- 账号、密码、证件、钱包全程只在你手里，不要发给任何人（包括聊天里）。
- 验证时提交的姓名/主体要与档案、证件三者一致，不一致是常见卡点。
- 验证未过期间，门户里做不了任何 App 相关操作，属正常，不是账号出问题。

## 你这边动起来时，我们这边并行的状态

文案字段稿、隐私政策、服务条款、banner 规格都在 `store/portal-prep/`
备好待换皮后替换 IP 名词；游戏侧的换皮（M3 硬门禁）与商店素材重渲
（M1）按主线排期走。你只需把「注册 + 主体选择 + 发起验证」这三件
起个头，剩下的等审批期间慢慢齐。
